# MVP 설계

한 줄: **Line, Bomb, Lightning** 세 종류를 매치와 로그라이트 업글로 키워서, 제한된 Move 안에 보스를 처치하고, 마지막 Bonus Chain에서 빌드를 폭주시켜 Final Burst를 만드는 매치3 로그라이트.

Match-3는 최종 목적이 아니다. 점화 장치다. 플레이어가 만드는 것은 연쇄반응 엔진이다.

---

## 1. 핵심 재미

플레이 감각이 한 판 동안 바뀐다.

| 구간 | 플레이어 | 감각 |
| --- | --- | --- |
| 초반 | 직접 Match | 내가 퍼즐을 푼다 |
| 중반 | 특수 타일 연결 | 내가 연쇄를 만든다 |
| 후반 | 빌드가 폭주 | 시스템이 보드를 박살낸다 |

계속 생각해야 하는 것은 두 가지뿐이다.

- 지금 어디를 Match할까
- 레벨업 셋 중 뭐가 제일 재밌어 보이지

잘 몰라도 된다. 아무거나 골라도 게임은 `펑 → 펑 → 촤악 → 빠지직 → 쾅`으로 진행된다. 깊게 파는 사람에게만 빌드 조합이 있다.

진입은 Candy Crush, 성장 쾌감은 Vampire Survivors.

---

## 2. 한 판 루프

Match → 특수 생성 → 발동 → 연쇄 → 보스 피해 → XP → 3택 1 → 더 강한 연쇄 → 보스 처치 → Bonus Chain → Final Burst → 클리어.

구간 미션, 서브 목표 없음. 흐름을 끊지 않는다.

- **승리:** 해당 스테이지 보스 처치
- **패배:** Moves = 0

승리는 보스 처치 순간에 이미 확정이다. Bonus Chain은 추가 전투가 아니라 도파민 결산이다.

---

## 3. Move

시간 제한이 아니라 Move 기반. 예: Moves 30.

일반 매치(플레이어 스왑) 1회 = Move -1. 캐스케이드와 특수 연쇄는 Move를 쓰지 않는다.

Move 자체도 빌드의 일부다. 잘 터뜨리면 Move를 벌고, 더 플레이한다.

MVP Move 회복은 한 종류만 넣는다.

- Chain 15 달성 시 Move +1 (레벨업 능력)

레벨업 시 +2 Moves, 폭탄 4개 동시, 라인 3줄 동시 같은 조건은 이후 테스트.

---

## 4. 특수 타일 3종

Color / Gravity / Clone / Fire / Freeze / Nuclear는 MVP 밖.

재미의 핵심은 종류 수가 아니라, **세 개가 붙었을 때 폭주하는가**.

| 타일 | 생성 | 기본 효과 | 역할 |
| --- | --- | --- | --- |
| Line | 같은 색 4개 일렬 | 해당 가로 또는 세로 한 줄 삭제 | 직선 |
| Bomb | T 또는 L | 3×3 폭발 | 근거리 광역 |
| Lightning | 2×2 | 떨어진 타일 연쇄 타격. 특수 타일 우선 | 원거리 점화 |

가로 4 = 가로 Line. 세로 4 = 세로 Line.

같은 색 3개 = 일반 삭제.

### 잠긴 생성/발동 규칙

- 특수 타일은 **생성 후 보드에 남는다.**
- 발동: 같은 색 매치에 포함 / 다른 특수 효과 범위에 히트 / 특수끼리 스왑 / 자동 점화 때 직교 인접 특수와 합성.
- 업그레이드가 “생성 즉시 발동”을 켠다. 그때 옆에 특수가 있으면 스왑 레시피와 같다. 초반은 퍼즐, 후반은 자동.
- 특수 타일도 원래 색을 가진다. 같은 색 매치에 들어가면 그 특수가 발동한다.
- Line이 특수 칸을 지나가면 그 특수 Activate. 이게 이벤트 연쇄의 기본 연료.

### Lightning 밸런스 (잠김)

2×2는 4일렬보다 쉽다. 자주 나오는 것이 점화 역할이다.

- 생성: 2×2 그대로
- 기본 타겟: **2**
- 특수 타일 우선 타격
- 업글: Lightning 대상 +2

웹 테스트에서 종류별 생성 횟수를 계측한다. 후반이 번개만 되면 숫자로 조절.

---

## 5. 매치 겹침과 우선순위

한 스왑에서 여러 클러스터가 나오면 전부 처리한다.

우선순위: **Bomb (T/L) > Line (4+) > Lightning (2×2) > 3매치.**

더 큰/특수 패턴을 먼저 쓰고, 남은 칸만 3매치.

가로 3 + 세로 3이 만나면 T → Bomb.

5개 이상 일렬은 MVP에서 그냥 Line. 추가 보상 없음.

특수 생성 위치: 방금 움직인 칸.

---

## 6. 특수 조합

외우는 게임이 아니다. 붙이면 더 미친 일이 일어난다.

동종 3 + 이종 3 = 6종.

| 쌍 | 결과 방향 |
| --- | --- |
| Bomb + Bomb | 대형 폭발 |
| Line + Line | 다줄 또는 십자 |
| Lightning + Lightning | 타겟 폭증 |
| Bomb + Line | 폭발 후 여러 Line |
| Bomb + Lightning | 번개가 폭탄을 점화 |
| Line + Lightning | 보드 곳곳에서 Line 점화 |

트리거 (잠김):

1. **공간 연쇄** — 효과 범위에 다른 특수가 있으면 Activate. 몰라도 동작.
2. **스왑 레시피** — 특수끼리 스왑하면 6종 테이블이 효과를 증폭.
3. **자동 점화 인접** — 생성(또는 잔류) 즉시 발동할 때 직교 인접한 특수가 있으면 스왑과 같은 레시피. 대각선은 아님. 파트너는 하나.

구현은 타일 코드 안에 `if Lightning`을 넣지 않는다. 이벤트 → `Activate()`. 상세는 [web.md](web.md).

---

## 7. 로그라이트

경험치를 얻으면 캐스케이드가 끝난 뒤 게임이 잠시 멈춘다. 능력 3개 중 하나.

설명은 매우 짧게. 퍼센트·조건부 계산 문장 금지.

나쁜 예: “Chain 8 이상에서 빨간 타일이 12% 확률로 번개로 변환”

### MVP 능력 풀 (6장)

- Bomb 범위 +1
- Line +1줄
- Lightning 대상 +2
- 특수 타일 생성 확률 증가
- 특수 타일이 다른 특수 타일 즉시 발동
- Chain 15 달성 시 Move +1

플레이어는 이번 런의 방향만 고른다. Bomb이 커졌다 / Line이 많이 나간다 / 번개가 폭탄을 찾아다닌다. 그 정도 판단으로 충분해야 한다.

혼합도 가능하다. Bomb + Lightning, Line + Lightning, Bomb + Line.

---

## 8. 보스

클리어 조건: Moves가 0이 되기 전에 보스 처치.

특정 빌드를 강제하지 않는다. “이번 보스는 이 빌드가 특히 잘 먹히네” 정도.

예 (MVP 이후):

- 갑옷 골렘 — 주변 장애물 → Bomb / Line이 자연스럽게 좋음
- 군체 — 여러 타겟 → Lightning이 자연스럽게 좋음
- 긴 형태 — Line이 시원하게 먹힘

**미확정 제안:** MVP 보스는 HP 바 + 이름만. 보드 위 잡몹·장애물 없음. 지운 타일 수 = 피해.

---

## 9. Bonus Chain

보스 처치 후 바로 결과창을 띄우지 않는다. 가장 잘 자란 빌드를 즐길 시간이 없다.

- 실패 없음
- 연쇄가 일어날 때마다 Bonus Energy 증가
- 종료 A: 연쇄가 끊김
- 종료 B: Energy가 임계치 → **Critical Mass** → 남은 특수 전부 강제 발동 → **Final Burst** → 스테이지 종료

강한 빌드가 계속 특수를 만들어도 임계치를 넘는 순간 종료 시퀀스가 시작된다. 무한 루프 없음.

임계치는 스테이지마다 다르다. 고정 100이 아니다. 후반일수록 Bonus Chain이 더 길고 화려해야 한다. 강한 빌드의 Final Burst가 3초에 끝나면 실패다.

| Stage | 예상 성장 | 임계치 예 |
| --- | ---: | ---: |
| 1 | 낮음 | 50 |
| 2 | 보통 | 80 |
| 3 | 중간 | 120 |
| 4 | 높음 | 200 |
| 5 | 매우 높음 | 300+ |

정확한 숫자는 플레이테스트. MVP는 스테이지 1만.

Final Burst는 추가 전투가 아니다. “이번 런에서 네가 이런 괴물을 만들었다”를 보여주는 연출.

CHAIN 숫자 상승 → CRITICAL MASS → 슬로모 → 모든 Bomb / Line / Lightning 발동 → FINAL CHAIN → RUN COMPLETE.

**미확정 제안:** Bonus Chain 동안 플레이어 스왑 없음. 남은 특수와 낙하 매치만 자동으로 돈다.

---

## 10. 기본값 (숫자, 반대 없으면 이걸로)

나중에 플레이테스트로만 조절하는 값.

| 항목 | 값 |
| --- | --- |
| 보드 | 8×8, 색 5 |
| 조작 | 인접 스왑. 매치 없으면 튕김 |
| Move 소비 | 플레이어 스왑 1회만 -1 |
| 교착 | 매치 없으면 셔플 |
| 데미지 | 이번 해석에서 지운 타일 수 |
| XP | 지운 타일 수. 연쇄 배율은 나중에 |
| MVP 스테이지 | 1개. Moves 30. 보스 HP는 플레이테스트 |

---

## 11. 미확정

코딩 전에 아직 안 고른 것.

1. Bonus Chain 동안 입력 — 제안: 자동
2. 보드 위 적 — 제안: 보스 HP만

## 12. 확장 (지금은 안 넣음)

시스템적으로는 처음부터 `SpecialTile` 공통 개념.

- 생성 조건
- 발동 조건
- 타겟 선택
- 기본 효과
- 연쇄 가능 여부
- 다른 특수와의 Interaction (이벤트, 직접 if 아님)
- Upgrade 목록

이후 후보: Color (색 전체 제거), Gravity (재배열/집결), Clone (특수 복제).
