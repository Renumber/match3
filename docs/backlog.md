### 3. 상태 기계

지금은 `idle` / `levelUp` / `win` / `lose` + 렌더러 `busy`. Bonus / Burst는 없음.

- [ ] `Idle / Resolving / LevelUp / Bonus / Burst / Win / Lose`를 엔진이 단계로 소유. Pixi는 재생만

파일 이름은 `web.md` 제안 (`fsm.ts`)을 따라도 되고, `game.ts`에 둬도 됨. 렌더러에 승패를 넣지 말 것.

### 4. Bonus Chain + Final Burst (P4)

- [ ] 보스 처치 후 자동 연쇄. 실패 없음. 플레이어 스왑 없음 (제안, 미확정)
- [ ] 연쇄마다 Bonus Energy. 끊기면 종료 A
- [ ] 임계치 → Critical Mass → 남은 특수 강제 발동 → Final Burst → 스테이지 종료
- [ ] 무한 루프 금지. 스테이지 1 임계치는 플레이테스트 (예: 50)
- [ ] 연출: CHAIN → CRITICAL MASS → 슬로모 → 전부 발동 → RUN COMPLETE

질문 6: Bonus Chain이 보상처럼 느껴지는가.
