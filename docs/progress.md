# 개발 현황

한 줄: **Match → 특수 → 연쇄 → XP → 3택 → 보스 피해 → 승/패**까지 웹에서 돈다. 특수끼리 스왑하면 콤보 증폭. 자동 점화는 인접 특수도 같은 레시피. Bonus Chain, Final Burst는 아직 없다.

설계는 [mvp.md](mvp.md). 목표 구조는 [web.md](web.md). 남은 일은 [backlog.md](backlog.md).

---

## 기록 규칙

플레이어가 느끼는 것, 엔진 규칙, 카드/훅이 바뀌면 **이 파일 맨 위(지금 있는 것 + 로그 최상단)**에 적는다.

1. 아래 **지금 있는 것**을 현재 코드에 맞게 고친다.
2. **로그** 맨 위에 `### YYYY-MM-DD — 한 줄`을 추가한다.
3. [backlog.md](backlog.md)에서 해당 항목을 체크하거나 옮긴다.

적지 않는 것: 오타, 테스트만, 리팩터만(구조가 안 바뀌면).

로그 형식:

```text
### YYYY-MM-DD — 한 줄 요약
- 무엇을 / 왜
```

### 엔진 `src/engine/`

- 매치 우선순위: Bomb (T/L) > Line (4+) > Lightning (2×2) > 3매치. 생성 위치는 방금 움직인 칸.
- 특수 3종: Line(가로/세로), Bomb(기본 3×3, 반경 캡 3), Lightning(기본 타겟 2, 특수 우선).
- resolve: 매치 → 생성 → 발동 → 중력. 범위 안 특수는 Activate. 특수끼리 스왑은 `combo.ts` 레시피. 자동 점화도 직교 인접 특수에 같은 레시피. Bomb+Lightning / Line+Lightning은 번개 타격 칸에서 서브 폭탄·라인 발동. 스텝 상한 80. 갑옷 판은 자리 고정, 보석은 판을 건너 낙하.
- 업글은 `upgradeStats` 숫자/플래그 + `upgradeRules` 훅. `game` / `resolve` / `specials`에 카드별 `if` 없음.
- 보스는 `data/bosses.ts` 기믹 목록 + `engine/boss.ts` 적용. `game`에 보스명 `if` 없음. 새 기믹은 def 추가 + `boss.ts` case.
- 런: Moves 30, 보스 골렘 HP 30 / 갑옷 판 4장(1타, 파괴 1, 초반 재생성). HP 10 이하 후반: 남은 목숨만큼 분노 판, 재생 없음. 매치는 XP만. 페이즈 `idle` / `levelUp` / `win` / `lose`. 교착 셔플.
- vitest: match, gravity, resolve, specials, combo, game, run, boss, levelUp, upgrades, upgradeRules, upgradeInfo, rng.

### 보드 / HUD

- PixiJS v8. 이벤트 타임라인 재생 (스왑, 튕김, 하이라이트, 발동, 라인/폭탄/번개 FX, 낙하). 갑옷은 앞 레이어, 보석 낙하는 뒤로.
- 입력: 탭-탭, 스와이프. resolve 중 `busy`.
- HUD: Moves, Level, Chain, Cleared, XP. 보스 바 30칸(앞 20 돌, 뒤 10 다이아). 후반 뱃지. 보유 카드는 상태 탭. 페이지 스크롤 없음.
- 레벨업 모달, 승/패 결과, 도감(카드/이번 런 스탯·보유 카드).
- Amplify: `amplify.yml` (`npm test` + `vite build`).

### 레벨업 카드 (14)

공통: 폭탄 확대, 직선 추가, 번개 증폭, 특수 생성, 경험 흡수.
핵심: 자동 점화 (`core`, 3택 한 칸 고정). 생성 즉시 발동 + 인접 합성.
고급: 십자 절단, 십자 폭파, 파편 폭탄, 잔류 번개, 낙뢰.
희귀: 체인 호흡, 특수 호흡, 숨 고르기.

뽑기: 희귀도 가중치 + 보유 태그 친화도. 스택/캡 다 쓴 카드는 제외.

잔류 특수(`plain`): 업글 스탯 없이 기본 효과만. 폭탄 반경 캡 3, echo 캡 폭탄 4 / 번개 2.

## 설계와 다른 점

- 자동 점화: 생성 즉시 발동. 직교 인접 특수가 있으면 스왑과 같은 레시피.
- MVP 카드 6장 제안 → 코드 **14장** + 희귀도/핵심 칸.
- 웹 폴더안 `fsm.ts` / `bonus.ts` / `bonusOverlay.ts`는 아직 파일 없음. 승/패는 `game.ts` 페이즈.

## 로그

### 2026-09-01 — 골렘 30칸, 후반 분노 판

- 여유 Moves면 클리어가 헐거웠다. Moves 30, 판 30장=처치.
- HP 10부터 후반. 남은 목숨만큼 빨간 다이아 판을 한 번에 깔고 재생 없음. 바 뒤 10칸이 그 구간.

### 2026-09-01 — 보유 카드는 상태 탭

- HUD 칩이 보드를 밀고 플레이 중엔 안 봄.
- 메인에서 빼고 상태(도감 런 탭) 맨 위에 목록.

### 2026-09-01 — 갑옷 뒤로 낙하

- 판이 중력 기둥을 잘라서, 아래 구멍이 위 보석이 아니라 새 타일로 채워졌다.
- 보석은 판 칸을 건너 떨어지고, 판 스프라이트는 앞 레이어.

### 2026-09-01 — 골렘 갑옷 판

- 숫자 갑옷이면 매치만 해도 HP가 녹아서 너무 쉬웠다.
- 보드 위 갑옷 4장, 3타에 파괴, 파괴당 50 피해, 다른 칸에 다시 깐다. 매치는 XP만.

### 2026-09-01 — 보스 기믹 카탈로그

- 골렘 갑옷/핵이 `game.ts`에 박혀 있으면 다음 보스마다 그 파일을 건드린다.
- `data/bosses.ts` 기믹 목록 + `engine/boss.ts` 적용. 카드와 같은 길. 플레이 숫자는 그대로.

### 2026-09-01 — 골렘 핵, 칩을 XP 줄에

- 카드 칩이 새 줄을 만들어서 페이지가 스크롤됐다. XP 줄에 붙이고 `overflow: hidden`.
- 보드 중앙 2×2 핵. 스왑/매치 불가, 특수만 파괴. 핵 파괴도 갑옷을 깨움. 번개가 핵 우선.

### 2026-09-01 — 골렘 갑옷

- HP만 있으면 스펀지라서, 갑옷 N이 피해를 깎는다. 특수 발동 1회마다 갑옷 −1 (이번 스왑에서 먼저).
- 보드 장애물 없음. XP는 지운 타일 그대로.

### 2026-09-01 — 보유 카드 칩 한 줄

- 칩이 줄바꿈되면 HUD가 보드를 밀어 잘렸다. 한 줄 가로 스크롤로 높이를 고정.

### 2026-09-01 — 보스 HP, 승패, 셔플

- 스테이지 1 보스 골렘 HP 300. 이번 resolve 지운 타일 = 피해.
- 처치하면 승리. Moves 0이고 보스가 살아 있으면 패배. 결과 화면에서 다시.
- 교착(가능한 스왑 0, 인접 특수 포함)이면 셔플.

### 2026-09-01 — 특수 생성 카드 문구

- “3매치에서도 나올 수 있다”처럼 켜기처럼 읽히던 설명을, 고를수록 확률이 오른다는 뜻으로 바꿈.

### 2026-09-01 — 자동 점화 인접 합성

- 자동 점화가 켜지면 스왑으로 합칠 수 없으니, 생성·잔류가 터질 때 직교 인접 특수도 `combo.ts` 레시피로 발동.
- 같은 틱에 생긴 특수끼리 먼저 짝을 찾고, 없으면 보드에 있던 인접 특수와 합성. 대각선은 아님. 파트너는 하나.

### 2026-09-01 — Bomb/Line + Lightning 서브 발동

- Bomb+Lightning: 번개가 친 칸에서 기본 폭탄이 바로 터짐.
- Line+Lightning: 번개가 친 칸에서 스왑한 방향의 라인이 바로 터짐.
- 공간으로 걸린 다른 번개에는 안 옮김.

### 2026-09-01 — 특수 스왑 콤보

- 특수끼리 스왑하면 매치 없어도 둘 다 발동. Move 1 소모.
- `combo.ts` 레시피가 그 쌍만 증폭 (폭탄 반경, 추가 줄, 번개 타겟). 범위로 걸린 다른 특수는 기본 업글만.
- lineH+lineV도 같은 Line+Line 취급.

### 2026-08-31 — 카드 희귀도, 핵심 칸

- 일반/고급/희귀 가중치. `core` 카드는 3택 한 칸을 항상 차지.
- 자동 점화를 핵심으로 고정. 초반부터 폭주 방향을 고르게.

### 2026-08-31 — 잔류 특수, 도감, 폭탄 캡

- 파편 폭탄/잔류 번개가 보드에 `plain` 특수를 남김. 낙하 후 발동.
- 도감: 카드 풀 + 이번 런 스탯.
- 폭탄 반경 상한 3. 보드 전체를 한 방에 지우지 않게.

### 2026-08-31 — 업글 훅 레지스트리

- 새 규칙은 `upgradeStats` → `upgradeRules` → 카드. 엔진 본문에 카드 `if` 금지.
- 자동 점화 특수가 소모되게 고침. 안 지워지면 무한 발동.

### 2026-08-31 — Move 40, 3매치 특수, 태그 가중치

- 기본 Moves 40.
- 특수 생성 카드가 3매치에서 Line/Bomb/Lightning을 가중 추출.
- 같은 태그 카드를 많이 들고 있으면 그 빌드가 더 잘 나옴.
